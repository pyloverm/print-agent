# Qomanda Print Agent

A desktop application for restaurant printing, built with Tauri v2, React, TypeScript, and Rust.

## Features

- Dashboard with agent status and controls
- Configuration page for server settings
- Printers management
- Logs viewing
- About page with application info

## Installation

```bash
npm install
npm run tauri dev
```

## Build

```bash
npm run tauri build
```
